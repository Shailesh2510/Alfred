# Alfred UI
Alfred is a food delivery portal where users can order food to their hotel room. The system includes four portals: one for users to place orders, one for hotel management to manage vouchers and view active orders, a merchant portal for the kitchen to track active orders, and an admin portal for adding new hotels, merchants, registering new users, editing meal periods, and publishing new menus.
 
# Development
## Tech Stack
* Next.js
* Mantine (styling library)
 
## Debug 
To debug the project locally:
 
Clone the repository:
```bash
git clone https://github.com/Alfred-Technologies/alfred-ui.git
```
Navigate to the shared UI folder and install dependencies:
```bash
cd shared/ui
npm install
```
 
Open the respective portal folder and install dependencies:
```bash
cd ../portal-folder-name
npm install
```
To run the project, use : 
```bash
npm run dev
```

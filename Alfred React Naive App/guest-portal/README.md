# Expo App

A modern React Native application built with Expo, React Native Paper, React Query, and NativeWind.

## Tech Stack

- **Expo**: Application framework
- **React Native Paper**: UI component library
- **React Query**: Data fetching and state management
- **NativeWind**: Utility-first styling

## Project Structure

- `src/api/`: API layer and data fetching
- `src/components/`: Reusable UI components
- `src/hooks/`: Custom React hooks
- `src/navigation/`: Navigation configuration
- `src/screens/`: Application screens
- `src/store/`: Global state management
- `src/theme/`: Theme and styling
- `src/utils/`: Utility functions

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Run on specific platform:
   ```bash
   npm run web     # for web
   npm run ios     # for iOS
   npm run android # for Android
   ```

## Development Guidelines

- Use TypeScript for type safety
- Follow the folder structure guidelines in each directory's README
- Use React Native Paper components for UI
- Style with NativeWind utility classes
- Use React Query for data fetching and caching
